# KAVOOM

משחק קווים לדפדפן: כל שחקן משאיר שובל, ומי שנוגע בשובל או בקיר נפסל.
2 עד 6 משתתפים על מכשיר אחד או אונליין בחדרים, עם בוטים, בונוסים, עברית ואנגלית.

## הרצה

```
npm install
npm start          # http://localhost:8080
```

השרת מגיש את האתר וגם מריץ את חדרי האונליין (WebSocket בנתיב `/ws`).
משחק מקומי עובד גם מכל אחסון סטטי. אונליין דורש את השרת הזה.

## העלאה לרשת (Render, חינם)

1. נכנסים ל-render.com עם חשבון GitHub.
2. New → Blueprint, בוחרים את הרפו. Render קורא את `render.yaml` ויוצר שירות חינמי.
3. אחרי כמה דקות המשחק זמין בכתובת `https://<שם>.onrender.com`.

עדכון: כל push לענף `main` מעלה גרסה חדשה לבד.

בשירות החינמי השרת נרדם אחרי 15 דקות בלי שימוש, והכניסה הראשונה אחרי זה לוקחת
בערך דקה. אם האתר הסטטי מתארח במקום אחר מהשרת, מגדירים את כתובת השרת ב-`SERVER_URL`
שבקובץ `js/config.js`.
